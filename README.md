| Problem | Topic | Pattern | Key Idea |
|---|---|---|---------------------------------------------------------------------------------------------------------------|
| [Largest Element](https://takeuforward.org/plus/dsa/problems/largest-element?source=strivers-a2z-dsa-track) | Arrays | Traversal | 🟢 Easy • ⏱ 5 min<br><br>**Approach:**<br>Single-pass traversal.<br>Initialize `largest` with `nums[0]` and iterate from index 1, updating whenever a bigger element is found.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Second Largest Element](https://takeuforward.org/plus/dsa/problems/second-largest-element?source=strivers-a2z-dsa-track) | Arrays | Traversal | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>Single pass tracking both `largest` and `secondLargest` simultaneously, updating both as new maxima are found.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Check if Array Is Sorted and Rotated](https://leetcode.com/problems/check-if-array-is-sorted-and-rotated/) | Arrays | Traversal | 🟢 Easy • ⏱ 15 min<br><br>**Approach:**<br>Walk the array twice (treat it as circular) counting consecutive non-decreasing pairs.<br>If the streak ever reaches N, the array is a rotated sorted array.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Remove Duplicates from Sorted Array](https://leetcode.com/problems/remove-duplicates-from-sorted-array/description/) | Arrays | Two Pointers | 🟢 Easy • ⏱ 15 min<br><br>**Approach:**<br>Two-pointer in-place overwrite.<br>`left` marks the next unique slot; advance `right` and copy over whenever a new unique value is found.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Rotate Array](https://leetcode.com/problems/rotate-array/) | Arrays | Two Pointers | 🟡 Medium • ⏱ 15 min<br><br>**Approach:**<br>Reverse the entire array, then reverse the first k elements and the remaining elements separately.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Move Zeroes](https://leetcode.com/problems/move-zeroes/) | Arrays | Two Pointers | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>Two-pointer swap.<br>`left` tracks the next position for a non-zero element; swap it forward as `right` scans ahead.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Max Consecutive Ones](https://leetcode.com/problems/max-consecutive-ones/) | Arrays | Sliding Window | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>Single pass tracking the current streak of 1s and the max streak seen so far, resetting on every 0.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Single Number](https://leetcode.com/problems/single-number/) | Arrays | XOR | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>XOR every element together — identical pairs cancel out to 0, leaving only the unique number.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Two Sum](https://leetcode.com/problems/two-sum/) | Arrays | Hashing | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>Hashmap storing seen numbers and their indices.<br>For each element, check whether its complement (`target - num`) already exists in the map.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(n) |
| [Two Sum II - Input Array Is Sorted](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/) | Arrays | Two Pointers | 🟡 Medium • ⏱ 10 min<br><br>**Approach:**<br>Two pointers from both ends of the sorted array, shrinking the window based on whether the current sum is above or below the target.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/) | Arrays | Two Pointers | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>Fill from the back.<br>Compare the last elements of both arrays and place the larger one at the end of `nums1`, working backwards.<br><br>**Complexity:**<br>Time: O(m+n)<br>Space: O(1) |
| [Missing Number](https://leetcode.com/problems/missing-number/) | Arrays | XOR | 🟢 Easy • ⏱ 10 min<br><br>**Approach:**<br>XOR every index with every value — all matched pairs cancel out, leaving the missing number as the leftover.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(1) |
| [Subarray Sum Equals K](https://leetcode.com/problems/subarray-sum-equals-k/) | Arrays | Prefix Sum | 🟡 Medium • ⏱ 30 min<br><br>**Approach:**<br>Running prefix sum + hashmap of prefix-sum counts.<br>At each step, count how many times `(sum - k)` has occurred before — each occurrence marks a subarray summing to k.<br><br>**Complexity:**<br>Time: O(n)<br>Space: O(n) |
